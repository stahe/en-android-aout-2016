## 📖 Overview

This document is a rewrite and consolidation of several educational resources on Android development. It aims to provide a **gradual and structured introduction** to Android application programming, particularly for tablets.

It incorporates several major developments:

* Adoption of **Android Studio** as the primary development environment
* Use of the **Gradle** build system
* Introduction of **RxJava** for handling asynchronous operations
* Advanced structuring of Android applications (fragments, lifecycle, client/server architecture)

A key feature of this document is the presentation of a **generic client/server Android application framework**, which can be reused in numerous projects.



---

## 🎯 Learning objectives

* Understanding the basics of Android development
* Mastering navigation between views and fragments
* Managing the lifecycle of Android components
* Implementing client/server architectures
* Manipulating data via user interfaces
* Introducing asynchronous programming with RxJava
